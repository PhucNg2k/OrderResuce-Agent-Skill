# Implementation status — 2026-10-31

The active application is the repository-root TypeScript app. It uses VoltAgent `Agent.streamText` with the server-side OpenAI provider and defaults to `gpt-6.1-terra`. The stale 2026-10-29 DeepSeek/direct-AI-SDK status has been superseded.

The current mode is `demo-multiturn-v1`: up to two buyer questions and three assessment turns, early stop, actual chronological Q&A context, per-assessment snapshots/history, final assessment links, no-reply selection of the latest completed result, and targeted semantic verification before a retry recommendation. The public BI assessment schema remains six fields. This authorized multi-turn demo extension is not a claim of untouched BI v2.2 compliance.

The harness preserves model-claimed supporting text for provenance validation. Assessment and verifier calls have configured timeouts; interrupted processing rows are reconciled to human review on startup, and retries are not automatic. The current browser integration suite includes deterministic boundary stubs through the actual Hono API and temporary SQLite. Bounded live OpenAI runs exercised assessment and verification; outcomes include fail-closed review on unsupported spans/address and one incomplete JSON response; see [mvp-readiness.md](mvp-readiness.md) and [live-check-2026-10-31.md](live-check-2026-10-31.md).

The Node environment is pinned to 22.14.0. Current offline verification: typecheck, 25 Node tests, build, 3 Playwright tests, and a compiled `npm start` plus `/healthz` smoke pass. A final bounded synthetic live assessment exited naturally after shared VoltAgent observability and the provider dispatcher were shut down. Earlier live model outputs included an unsupported verifier span, incomplete JSON, and conservative address support, so live semantic reliability is not passed. A separate reset control, public demo access protection, and the missing authoritative BI 30-case evaluation remain open. Synthetic fixtures do not establish real operational readiness.
